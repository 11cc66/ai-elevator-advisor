# 03 — 业务规则、状态、权限与版本

## 1. 核心层级

企业 → 项目 → 建筑 → 电梯安装单元 → 设备档案。

- 一个项目可包含多栋建筑。
- 每栋建筑可包含多个安装单元。
- 安装单元代表一个拟安装 / 改造的电梯业务对象。
- 设备档案在设备正式交付后建立或转为正式设备身份。
- 项目、建筑、安装单元和设备均有独立稳定编号。
- 每个文件必须关联到正确项目；需要时进一步关联建筑、安装单元。
- 设备交付后仍保留与原项目、建筑和安装单元的关联。

## 2. 工程数据来源和状态

每条工程数据至少保存：
- 字段名称和值；
- 单位；
- 来源类型；
- 来源文件 / 测量记录；
- 录入者 / 确认者；
- 记录时间；
- 状态；
- 版本；
- 备注 / 冲突信息。

来源类型：
- CUSTOMER_STATED：客户口述 / 填写；
- DOCUMENT_EXTRACTED：图纸或文件识别；
- PHOTO_INFERRED：照片辅助识别（只能作为线索）；
- FIELD_MEASURED：现场测量；
- PROFESSIONAL_CONFIRMED：专业人员确认；
- SYSTEM_DERIVED：系统按明确规则计算得出。

状态：
- UNCONFIRMED：未确认；
- CUSTOMER_CONFIRMED：客户确认（仅普通信息）；
- PENDING_VERIFICATION：待核实；
- PROFESSIONALLY_CONFIRMED：专业确认；
- CONFLICTED：数据冲突；
- INVALIDATED：已作废 / 被新版本替代。

客户确认不得把工程数据直接升级为 PROFESSIONALLY_CONFIRMED。

## 3. 数据冲突

- 不同来源的值冲突时保留所有值。
- 不自动平均、不自动覆盖、不默认取最新值作为工程依据。
- 创建冲突事项，指派责任人核实。
- 核实结果通过新记录保存，旧记录保留。
- 正式选型只读取符合当前选型阶段要求的数据。

## 4. 项目 / 方案 / 报价版本

- 项目基本资料可有版本或变更历史。
- 选型方案每次实质修改产生新版本。
- 已审核方案不可原地覆盖。
- 客户意向绑定具体方案版本。
- 报价每次金额、费用、范围、产品或关键条件变更产生新版本。
- 已发布报价不能静默修改；旧版本保留并标记被替代 / 过期 / 撤回。
- 已签合同文件不得被替换；修订需走合同变更或新合同流程。
- 需求变更需记录提出人、时间、原因、变更前后值及影响对象。

## 5. 审核状态

选型技术审核：
- DRAFT；
- ENGINEER_REVIEW_PENDING；
- ENGINEER_REJECTED；
- ENGINEER_APPROVED；
- TECH_LEAD_REVIEW_PENDING；
- TECH_LEAD_REJECTED；
- TECH_LEAD_APPROVED；
- RELEASED_TO_CUSTOMER；
- SUPERSEDED / WITHDRAWN。

流程：工程师初审通过后，技术负责人终审；任一阶段退回，必须记录原因。技术终审通过前不能正式发布客户方案。

报价审核：
- DRAFT；
- COMMERCIAL_REVIEW_PENDING；
- COMMERCIAL_REJECTED；
- COMMERCIAL_APPROVED；
- RELEASED；
- EXPIRED / SUPERSEDED / WITHDRAWN。

正式报价需基于当前有效方案、有效价格依据和已核算费用。

## 6. 角色与权限（建议 RBAC）

- CUSTOMER：只能访问自己有权访问的项目和已发布内容；可上传资料、确认普通信息、表达方案意向。
- SALES：访问被分配客户 / 项目；可沟通、建立报价草稿，但不得绕过审核。
- SURVEY_ENGINEER：访问被分配勘察任务；可录入测量和勘察记录；不可自行把审核状态设为通过。
- TECH_ENGINEER：执行技术初审；不可替代技术负责人终审（若企业配置要求双人审核）。
- TECH_LEAD：技术终审、退回、批准。
- COMMERCIAL：维护报价草稿和费用明细。
- COMMERCIAL_LEAD：按授权审批报价。
- PRODUCT_ADMIN：维护产品资料、导入、查重、提交审核。
- SYSTEM_ADMIN：账号、角色、配置；不应自动拥有工程审核权限，除非另行授权。

所有权限在服务端验证。前端隐藏控件不是安全措施。高风险操作需记录审计日志。

## 7. 变更影响

关键变更可能影响：
- 项目资料状态；
- 勘察任务；
- 工程数据有效性；
- 产品筛选结果；
- 方案审核状态；
- 客户意向；
- 报价；
- 合同及后续业务。

系统应建立影响关联并通知责任人。不得自动撤销已签合同或已完成业务；应创建待处理的正式变更事项。
