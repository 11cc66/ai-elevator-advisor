# 11 — 待确认事项（不要由 Codex 擅自假设）

本文件记录需要产品方、真实业务人员或技术负责人确认的事项。

## 产品和业务
- [ ] 企业真实组织架构、角色名称和审批人配置。
- [ ] 首期是否只支持单台电梯安装单元。
- [ ] 项目、建筑、安装单元编号规则。
- [ ] 旧楼加装业务所需的必填资料清单。
- [ ] 勘察报告模板和必须由专业人员确认的字段。
- [ ] 经济 / 均衡 / 高配置方案的企业定义和排序权重。

## 工程与产品数据
- [ ] 真实产品库数据来源、授权和维护责任人。
- [ ] 各品牌型号技术参数的字段标准、单位和适用条件。
- [ ] 产品技术审核制度和复核周期。
- [ ] 产品价格口径：设备价、含税价、安装价、项目总价如何区分。
- [ ] 产品价格有效期和地区规则。
- [ ] 哪些工程字段属于正式选型硬约束，以及由谁确认。

## 技术和合规
- [ ] 最终技术栈和部署环境。
- [ ] 模型供应商、预算、数据处理和隐私要求。
- [ ] 文件存储位置、保留期限和删除政策。
- [ ] 真实客户数据是否允许用于模型处理。
- [ ] 适用地区的法律法规、数据保护和网络安全要求。
- [ ] 电子签约、短信、地图等第三方服务是否需要接入。

## 运营
- [ ] 客户服务和销售分配方式。
- [ ] 报价审批金额权限。
- [ ] 合同审核和生效核验流程。
- [ ] 售后、维保及外部服务商功能的 V1.0 优先级。
