# 10 — Codex 分阶段开发路线

## Phase 0：仓库检查与技术方案

交付：
- 检查当前仓库、运行环境和已有文件；
- 提出前后端、数据库、认证、文件存储和测试技术栈；
- 画出模块架构；
- 提出数据库 ER 草图；
- 提出目录结构；
- 说明本地启动方式和风险。

验收：先由产品方确认技术方案，再开始主体编码。

## Phase 1：可运行项目骨架

交付：
- 前端和后端基础项目；
- 数据库连接与迁移；
- 环境变量模板 `.env.example`；
- 健康检查接口；
- 基础日志和错误处理；
- README 启动说明；
- 最小自动化测试。

验收：本地可启动，健康检查和测试通过。

## Phase 2：认证、角色与项目管理

交付：
- 登录；
- RBAC；
- 客户、项目、建筑、安装单元；
- 项目列表和详情；
- 审计日志基础。

验收：不同角色访问范围正确，客户之间数据隔离。

## Phase 3：文件上传与资料管理

交付：
- 私有文件上传；
- 项目 / 建筑归属；
- 文件列表；
- 识别任务状态；
- DEMO 识别器或可替换 AI adapter；
- 识别结果确认与历史。

验收：原文件不被覆盖，字段来源和状态正确。

## Phase 4：勘察工作台

交付：
- 勘察任务分配；
- 测量数据录入；
- 照片和备注；
- 报告草稿、提交、审核；
- 数据冲突事项。

验收：未经审核的数据不能成为专业确认依据。

## Phase 5：产品库与确定性选型引擎

交付：
- 产品导入和校验；
- 产品技术 / 价格版本；
- 审核状态；
- 重复冲突检测；
- 硬约束筛选；
- 排除理由；
- 三档方案生成规则；
- DEMO 产品库。

验收：第 09 文档中产品库和选型相关用例通过。

## Phase 6：AI 顾问和方案解释

交付：
- 对话需求收集；
- 结构化提取；
- 资料缺失清单；
- 选型结果自然语言解释；
- 提示注入防护；
- AI 输出 schema 校验。

验收：AI 不能越权写入权威字段，硬条件由规则引擎执行。

## Phase 7：审核、报价与客户发布

交付：
- 技术初审、终审；
- 客户方案展示；
- 客户意向；
- 报价明细和版本；
- 商务审核；
- 正式发布。

验收：客户只看得到已发布版本；报价引用有效方案。

## Phase 8：联动回归与试点准备

交付：
- 全流程 E2E；
- 权限和安全检查；
- 数据备份 / 恢复方案；
- 日志与错误监控；
- DEMO 数据清理方案；
- 部署说明；
- 未解决问题清单。

验收：完成受控试点前评审。不得在没有真实产品资料、专业审核和合规评估时对外宣称可自动完成工程选型。
