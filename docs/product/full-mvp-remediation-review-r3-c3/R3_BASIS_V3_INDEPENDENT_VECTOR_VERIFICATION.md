# R3-BASIS-1 Revision 3 Independent Vector Verification

Date: 2026-11-24

## Method

Two independent in-memory implementations were written from the C3 protocol:

- Node.js `Buffer`/`crypto`;
- Python `struct`/`hashlib`.

The implementations independently:

1. normalized scalar values;
2. sorted fields by tag;
3. framed Fields and Records;
4. sorted Records by `(recordType, stableKey bytes, rowId bytes)`;
5. generated the 28-byte header and Basis bytes;
6. computed SHA-256;
7. compared against `R3_BASIS_V3_FIXED_VECTORS.md`.

No project file, database, Storage, migration, Runtime or test runner was used.

## Protocol Completeness Caveat

This report verifies the synthetic framing vectors. It does not approve the
full Snapshot Basis because the record/field registry and per-entity stableKey
mapping for actual Snapshot tables are not provided in the R3-C3 deliverables.
That is the independent P1 finding `REV-R3-C3-P1-02`.
