## Method

A second implementation was written independently in JavaScript using
`Buffer` and `crypto` only. It implemented the protocol from its normative
description:

- `R3BASIS\0` magic;
- uint16be format version 2 and payload type 1;
- uint32be header length 28;
- uint32be record count;
- uint64be body length;
- record length/type/UUID/stableKey/field count;
- field tag/type/presence/value length/value;
- type-specific scalar bytes;
- SHA-256 over the complete basis bytes.

No project file, database, Storage, migration, test runner or Runtime was
used. The expected vector values were copied from the R3-C2 test plan.

test plan records `0x29`. The same two-byte shift affects V01–V20.
